# Simple Dashboard Design QA

## 2026-09-09 documentation and interaction review

Current implementation and interaction contract:

- All three styles share global language/theme preferences and a 17-module
  picker with All/System/AI/default presets. Names are complete, and the normal
  Settings draft remains separate from immediately saved header controls.
- Small-card rows use available viewport height, with balanced layouts for
  smaller selections. Each card has a visible boundary and hover emphasis.
- Engraved Scale separates its fixed-width value ring from a five-second
  rotating inner arc. Values are stationary and share center anchors.
- Single-click/Enter/Space flips details. Double-click, F, or the expand icon
  opens the same live card in a native modal; double-click/F/Esc/exit restores
  its position and face. Background card animations pause while focused.

Validation evidence from the implementation review: 54 style/language/size/
viewport combinations and 15 style/theme combinations passed in Chrome via
Playwright (Browser plugin not available). Coverage included 390, 1280, 1440,
and 2326 px widths, filtering, minimum-one selection, reload, both language
directions, hover, focus entry/exit, live modal updates, and full/simple round trips.
The Python suite has 74 passing tests. Safari and physical mobile devices were
not tested; no fixed memory reduction or cross-platform performance SLA is claimed.

Public documentation screenshots use synthetic data only:

- [Tonearm editorial](docs/images/simple-tonearm.png)
- [Vinyl record](docs/images/simple-vinyl.png)
- [Engraved scale](docs/images/simple-engraved.png)

Reproduce with `node scripts/capture-docs.cjs` in an environment with Playwright
and Chrome; `PLAYWRIGHT_MODULE` optionally specifies the installed module path.
The script intercepts every HTTP request and serves repository static files and
fixtures, so it does not need a live server or read a real account/system API.
It verifies the intended page, nine cards, overflow at desktop/mobile widths,
full-window entry/exit, and console health before completing.
The output files are illustrative documentation, not live-performance evidence.

Historical local captures are intentionally excluded from Git because they
contain machine identity and obsolete layouts. They are not homepage previews.

## 2026-09-08 revision

The current implementation supersedes the fixed source dimensions and separate
Paper/Colophon theme described in the historical review below. At the user's
request, nine medium cards now form a balanced 3 by 3 grid on ultrawide screens,
card height uses available viewport height, and all three styles share the five
global dashboard themes. Footers are in normal layout flow; backs scroll when
needed. The independent surface selector has been removed.

The simple stream omits full process/session trees and hidden chart rendering.
Full-view arrays and heavy DOM are released on switching to simple mode;
offscreen, flipped, and background records pause animation. The macOS launcher
is generated by `scripts/install-macos-launcher.py` and reuses an existing server.

Current visual checks cover 390, 768, 1280, and 2326 px widths, all three styles,
five themes, three sizes, 9/17-card selection, flips, and full/simple round trips.
Screenshots from August below are historical and are not current UI evidence.

## Comparison result

### Full page

- Typography: Lora and Cormorant match the supplied source family and hierarchy.
- Color: Paper and Colophon use the source surface and ink tokens; metric accents
  stay mapped to live resource semantics.
- Geometry: A uses 238 px cards and 166 px records, B uses 156 px cards and 112 px
  records, and C uses a gapless 216 px tiled grid with 152 px scales.
- Responsive layout: one card per row at 390 px with no horizontal overflow;
  header controls wrap and retain at least a 44 px touch target.
- Content: nine cards are visible by default, including Claude, ChatGPT, and
  Cursor. The remaining eight live cards are available from the picker.

### Focused regions

- Record: live CSS rotation was observed across two samples 650 ms apart; the
  transform changed while the dashboard was running.
- Tonearm: arm angle follows the live percentage and the desktop card grid aligns
  with the supplied three-column editorial reference.
- Engraved scale: conic progress, marker, centered reading, rules, and gapless
  five-column desktop grid align with the supplied reference.
- Controls: S/M/L changes global card dimensions and persists; Paper/Colophon,
  card selection, flipping, drag/keyboard order, pause, and Full/Simple switching
  remain functional.

## Comparison history

1. Initial implementation reused six full-dashboard cards, approximated the
   reference with static concentric rings, and did not match source geometry.
2. Rebuilt the simple surface as a dedicated 17-card model, copied the measured
   A/B/C spacing and dimensions, added real rotation and tonearm motion, and added
   persisted size and surface controls.
3. Compared A, B, and C at identical desktop viewports. No P0, P1, or P2 visual
   mismatch remained. The deliberate differences are the requested AI cards,
   live values, and added card/size/settings controls.
4. Mobile QA found flex groups shrinking to 2 px and a 1 px horizontal overflow.
   The toolbar now wraps, groups no longer shrink, touch targets are 44 px, and
   measured overflow is 0 px.
